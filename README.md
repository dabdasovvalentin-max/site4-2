# Курсы IT — учебный сайт (site4)

Статический сайт для лабораторной работы по SEO и GitHub Pages.

## Структура

```
my-site/
├── index.html
├── about.html
├── contacts.html
├── style.css
├── robots.txt
├── sitemap.xml
└── images/
    ├── about-team.svg
    └── contacts-office.svg
```

## Что реализовано

- уникальные `title` и `meta description` для каждой страницы;
- ключевые слова в `meta keywords`, заголовках и тексте;
- структура заголовков `h1`–`h3`, один `h1` на страницу;
- изображения с содержательным `alt`;
- `canonical` и Open Graph для каждой страницы;
- адаптивная вёрстка и доступная навигация;
- `robots.txt` и `sitemap.xml` со всеми страницами;
- корректные URL для публикации на GitHub Pages.

## Публикация на GitHub Pages

1. Загрузите содержимое папки `my-site` в репозиторий GitHub
   (например, `dval-repo`).
2. В настройках репозитория включите GitHub Pages:
   `Settings → Pages → Deploy from a branch → main / root`.
3. Проверьте адрес `https://dabdasovvalentin-max.github.io/dval-repo/index.html`.
4. Отправьте `sitemap.xml` в Google Search Console и Яндекс.Вебмастер.
5. Подтвердите сайт в Яндекс.Вебмастере и проверьте раздел
   «Внешний вид в поиске».
